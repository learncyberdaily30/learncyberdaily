# Learn Cyber Daily Website

## Run locally
Open `index.html` in a browser. No build step or dependencies required.

## Publish free with GitHub Pages
1. Create/sign in to GitHub and make a repository (e.g. `learncyberdaily`).
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
4. Wait for GitHub Pages to publish; use the URL it provides.
5. Replace `learncyberdaily30` in `index.html` with your final Instagram handle if changed.

## Customize
- Colors and responsive layout: `styles.css`
- Filters, mobile menu, random tip: `script.js`
- Articles: `articles/`
- Logo: `assets/logo.svg`

This is a static educational site. The tip button works locally; there is no newsletter backend, CMS, login, or server-side AI integration.
